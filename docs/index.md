These are for vibe coders, people building AI agents, and anyone who ships small tools or posts about tech and games.

## What's inside

The free lite samples live in the `samples/` folder of [this project's GitHub repository]({{ site.github.repository_url | default: "https://github.com" }}):

- **Inbox Triage Agent (lite)** — sort new email into Action, Later or Needs you, and draft short replies. The agent never sends mail.
- **Content Repurposing Desk (lite)** — turn one transcript, post or set of notes into a short set of X posts, with no invented facts.
- **Ship-Ready Review Agent (lite)** — a first-pass review for leaked secrets and unsafe config before you put an AI-built app online.

Each sample is a starter: the core system prompt plus one workflow. It is not the full paid kit.

## Quick start

1. Open the sample folder in the GitHub repository.
2. Copy the system prompt into a custom GPT, a Claude project, Cursor rules, or your agent's instructions.
3. Copy the job prompt, add your mail, source text, or repo, and run it.
4. Read the output before you act on it. These agents draft and review. They do not send, post, deploy or delete.

## FAQ

**What is this site?**  
A landing page for free AI agent prompt templates from The Kit Ledger. The prompts themselves are in the public GitHub repository, ready to paste into ChatGPT, Claude, Cursor, or another agent.

**Are these the full kits?**  
No. Each sample is a useful starter — the core system prompt and one workflow. The paid kits add checklists, rubrics, extra prompts, output templates and setup guides. The comparison table above lists what each paid kit adds.

**Which agents do the prompts work with?**  
Any agent that accepts a system prompt or project instructions, including ChatGPT, Claude, Cursor and Claude Code. You do not need a particular paid plan to use the samples.

**Do the inbox or review agents send mail, post, or deploy?**  
No. The inbox sample drafts replies only. The content sample drafts posts only. The review sample must not push, deploy, or rotate credentials.
