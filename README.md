# Free AI agent prompt templates: inbox triage, content repurposing, code review

Lite, copy-paste prompt kits for ChatGPT, Claude, Cursor and similar agents. Each sample is useful on its own. The complete kits are sold by [The Kit Ledger](https://payhip.com/TheKitLedger).

These are for vibe coders, people building AI agents, and anyone who ships small tools or posts about tech and games.

## What's inside

Free lite samples of three kits:

- [Inbox Triage Agent (lite)](samples/inbox-triage-agent/) — sort new email into Action, Later or Needs you, and draft short replies. The agent never sends mail.
- [Content Repurposing Desk (lite)](samples/content-repurposing-desk/) — turn one transcript, post or set of notes into a short set of X posts, with no invented facts.
- [Ship-Ready Review Agent (lite)](samples/ship-ready-review-agent/) — a first-pass review for leaked secrets and unsafe config before you put an AI-built app online.

Each sample is a starter: the core system prompt plus one workflow. It is not the full paid kit.

## Quick start

1. Open one of the sample folders above.
2. Copy the system prompt into a custom GPT, a Claude project, Cursor rules, or your agent's instructions.
3. Copy the job prompt, add your mail, source text, or repo, and run it.
4. Read the output before you act on it. These agents draft and review. They do not send, post, deploy or delete.

## FAQ

**What is this repository?**  
A public set of free AI agent prompt templates from The Kit Ledger. You can paste them into ChatGPT, Claude, Cursor, or another agent.

**Are these the full kits?**  
No. Each sample is a useful starter — the core system prompt and one workflow. The paid kits add checklists, rubrics, extra prompts, output templates and setup guides. The comparison table above lists what each paid kit adds.

**Which agents do the prompts work with?**  
Any agent that accepts a system prompt or project instructions, including ChatGPT, Claude, Cursor and Claude Code. You do not need a particular paid plan to use the samples.

**Do the inbox or review agents send mail, post, or deploy?**  
No. The inbox sample drafts replies only. The content sample drafts posts only. The review sample must not push, deploy, or rotate credentials.

**How much do the full kits cost?**  
Inbox Triage Agent is £19, Content Repurposing Desk is £29, and Ship-Ready Review Agent is £24. Current prices are on the [Payhip shop](https://payhip.com/TheKitLedger).

**Can I use the samples in my own work?**  
Yes. The free samples in this repository are under the MIT licence. The paid kits are not in this repository and are not covered by that licence.
