# Contributing

This repository holds free lite samples of The Kit Ledger kits. The paid kits are sold separately and should not be pasted here.

## How to help

- Open an issue if a sample is unclear, broken in a particular agent, or missing a safety note.
- Request a new kit if you have a repeated problem that a tested prompt pack could fix. Use the kit-request issue template. Those requests help decide what to build next.
- Small fixes to the samples (typos, clearer steps, broken links) are welcome as pull requests.

## Please do not

- Paste or reconstruct a paid kit, or a substantial part of one.
- Add testimonials, star counts, or other claims that are not already in the repo.
- Submit generated “improvements” that invent features, prices, or results.

## Before you open a kit request

Say what problem you keep hitting, who it is for, and which tools you already use (for example ChatGPT, Claude, Cursor, Gmail, X). A short real example is more useful than a feature list.

Questions about a purchase or a file you already bought are better sent through the Payhip shop: https://payhip.com/TheKitLedger
